# machi-list

`machi-list` は、市区町村と店ジャンルを組み合わせた一覧ページを中心に、お店・商業施設を探せるサイトです。
現在のMVPは47都道府県の県庁所在地と主要都市に対応し、ネットカフェ、ゲームセンター、カラオケ、サウナ、スーパー銭湯・SPA・岩盤浴、猫カフェ、飲食店・居酒屋、ダーツ、ボウリング場、ビリヤード、映画館、ビデオボックス、カプセルトイ、クレーンゲーム・UFOキャッチャー、コンビニ、カフェ、本屋、古本屋を扱います。

地図は場所とルート確認の補助として置き、メインは市区町村ごとの一覧・比較ページです。

## 起動

```bash
npm start
```

URL:

```text
http://127.0.0.1:4173/
```

## 確認

```bash
npm run check
npm run generate
```

## 公開

`CNAME` は `machi-list.jp` に設定済みです。GitHub Pages を使う場合は、リポジトリの Pages 設定で Source を GitHub Actions にすると、`main` への反映時に `.github/workflows/pages.yml` が静的ページを生成して公開します。

## ページ生成

```bash
npm run generate
```

`data/areas.json`、`data/genres.json`、`data/shops.json` をもとに、都道府県ページ、市区町村ページ、ジャンル別ページ、`sitemap.xml` を生成します。

## OpenStreetMap から本屋・古本屋を取る

```bash
node scripts/fetch-osm-bookstores.js            # 全120エリア
node scripts/fetch-osm-bookstores.js --only=aichi
```

`shop=books` を取り込みます。走らせたあとは `normalize-data.js` → `generate-pages.js` の順です。

**OSM の住所タグはあてになりません。** 名古屋市千種区の本屋は5件ありますが、
`addr:*` が付いているものは0件でした（2026-09-07 実測）。名前と座標しかありません。
そこで住所は、座標から**国土地理院の逆ジオコーダ**を引いて組み立てます。
市区町村コードと町丁目が返るので、`愛知県名古屋市千種区内山三丁目` まで作れます。推測はしません。

**住所に都道府県名が無いページは `generate-pages.js` が noindex にします。**
都道府県まで入れられない店は載せません。名前だけのページを作らないためです。

取り込むときの決まりごとが3つあります。

- **名前の無い OSM 要素は捨てる。** 「自動販売機」のような無名データを増やさない
- **エリア名は `千種区` で引く。** `名古屋市千種区` では0件になります
- **どの市区町村かは市区町村コードで判定する。** Overpass は area の中の area を絞れないので、
  `中区` で引くと広島市中区や浜松市中区まで返ります

## 住所の並びを直す

```bash
node scripts/fix-address-order.js          # 直す内容を見るだけ
node scripts/fix-address-order.js --write
```

Google Places の英語表記をそのまま入れた住所が58件ありました。

```text
４丁目 尾上町 中区 横浜市 神奈川県 231-0015
```

**noindex 判定は「都道府県名が住所にあるか」しか見ない**ので、この形でも index されます。
横浜市中区の自動販売機ページは、この壊れた住所2件と広告行1件だけの内容で、
表示回数が60から0に落ちていました。

## 店舗データ

店舗データは `data/shops.json` に保存します。主な項目は、店舗名、ジャンル、市区町村、住所、営業時間、最寄り駅、徒歩目安、予算目安、駐車場、夜まで営業、クーポン確認、公式URL、予約URL、クーポンURL、通販URL、外部確認用の検索語です。

予約、クーポン、通販などの確認先はテキストリンクで掲載します。画像素材は使わず、一覧やサイドの自然な確認導線として扱います。ネットカフェやビデオボックスでは、終電後に休む人がシャワー、充電、軽食、備品を確認できる導線を置きます。コンビニやカフェでは、喫煙可否、電源、Wi-Fi、イートインを比較できるようにします。

通常は次のコマンドで、足りない項目の補完と並び替えを行います。

```bash
node scripts/normalize-data.js
```

Google Place ID が確認できた店舗は `source.google_place_id` に入れます。未確認でも、公式サイトや公開地図で確認した店舗は `source.google_query` を入れて、あとから同期しやすい形にします。

## 公開

GitHub Pages で公開する場合は、リポジトリ設定で Pages の公開元を `main` ブランチの root にします。

ドメイン:

```text
machi-list.jp
```

このリポジトリには `CNAME` と `.nojekyll` を置いています。
